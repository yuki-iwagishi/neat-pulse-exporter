# Sample column inventory

This is a representative list of columns produced by neat-pulse-exporter v0.1.0
against a real-world Pulse tenant (560 endpoints / 296 rooms / 25 profiles /
11 device models). Your output may differ depending on the device models
present and which configuration keys are actually written to each device.

For that tenant the export produced 219 columns. They are grouped, in this
order, by prefix: identity / room / profile metadata / firmware / NTP / misc /
network.* / storage.* / effective.* / config.* / profile.* / error.

## Device config (config.*)

  Same key set as effective.* (subset), containing only values actually
  written on the device. A blank cell means the value is either inherited
  from the profile or not supported by this model. See README §
  "Known Pulse API limitations" for details.

## Profile config (profile.*)

  Subset of keys declared by the device's assigned profile. Empty for
  devices without an assigned profile.

## Error/diagnostic (only present if anything failed)

  _error             # full row error (device couldn't be fetched at all)
  _configError       # device fetched OK but /config call failed
  _settingsError     # legacy fallback message
